## Existing code seam and newly confirmed gaps (read-only review, not a diagnosis of production acceptance)

1. `ExamPrepSection.tsx` currently obtains only `availableCourseMocks(course)`, selects a mock and passes it to `ExamSimulator`; it **does not pass** `preferredQuestionId` or offer a marks-first selector.
2. `ExamSimulator` already accepts `preferredQuestionId`, but resolves the target against **`exam.questions`**. This does **not** by itself support independent, paper-linked practice-only questions without a deliberate, reviewed adapter/catalogue contract. Never insert extra questions into the published timed mock question array and thereby alter paper totals/options.
3. In untimed question practice, `Show marking guidance` is enabled for any nonempty `practiceDraft.trim()`. Clicking it simply toggles `practiceGuidance`; the written textarea remains editable until the result is saved. Therefore the current UI does **not** freeze/commit the independent *first response* before guidance, and arbitrary token text can unlock the indicative guide. This is a precise mismatch with the proposed LF-05 first-attempt evidence contract.
4. The untimed Practice path does not use the timed `checkpointContext` recovery. The parent page's `Back to Exam Prep` unmounts the current question and its unsaved draft; no separate durable untimed written draft is proved. REC-10's 14-day timed mock retention **does not automatically authorise** long-answer untimed storage or children-data processing.
5. The existing exam question evidence path distinguishes self-awarded written AO marks from authored-key objective answers. Preserve that provenance, existing zero marks, frozen historical identities and owner isolation. A self-marked essay cannot independently establish weakness resolution, validated marks, predicted grade or mastery.

These are *observed code contracts* at the named main commit, not a completed authenticated/browser reproduction or a licence to change them during Analyse.
