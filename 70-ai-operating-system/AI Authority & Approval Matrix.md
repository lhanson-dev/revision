# AI Authority & Approval Matrix

| Activity | AI may inspect/propose | AI may implement on branch | Founder approval required before merge |
|---|---|---|---|
| Discovery / inventory | Yes | Yes | Yes |
| Product authority | Yes | Draft only | Yes |
| Implementation change | Yes | Yes | Yes |
| Documentation | Yes | Yes | Yes |
| Defect fix | Yes | Yes | Yes |
| Research | Yes | Yes | Yes |
| Governance change | Yes | Draft only | Yes |

No AI agent may interpret technical mergeability or passing tests as merge approval.
