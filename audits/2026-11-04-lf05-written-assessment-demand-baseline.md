## C. Current learner route and DoR discrepancies requiring resolution

- **Existing canonical route:** `/revision/app/` → Courses → Exam Prep → paper → Practise untimed. `ExamSimulator` already offers a typed field, stimulus, question mark value, *Show marking guidance* (button disabled until nonblank text), AO numeric self-marks and *Record this result*. `preferredQuestionId` exists but `ExamPrepSection` does **not** supply a selected question. Authored responses are **self-assessed**, not independently marked.
- **Raw written draft persistence gap:** `ExamSimulator`'s `practiceDraft` is React state and question navigation resets it. Untimed mode explicitly excludes timed exam's durable checkpoint. **The Founder's new requirement includes autosave/resume**. The earlier #813 candidate proposed *leave warning only*, which is insufficient. Proposal: owner-scoped, version/fingerprint-checked, per-`questionId` **raw written attempt draft** with clear status, explicit resume/discard, account isolation, expiry, safe conflict handling, failed-save recovery and privacy/retention authority. Reuse REC-10 secure service patterns only after scope/retention/privacy are approved; do not claim existing 14-day exam checkpoint already covers this route or turn on any raw child-data processing prematurely.
- **Commit/reveal invariant:** typed text existing is enough to enable guidance. Founder now requires *first committed attempt* before seeing a model, not mere text entered. Add a frozen written-answer first-attempt state; changes after model reveal are explicit next-version revisions, never recast as independent first attempt.
- **Navigation tension:** previous #813 draft leads with `Practise by marks` under paper-oriented Exam Prep; the new Founder request specifically prioritises `Subject → Topic → question type/mark → Practise`. Proposed resolution for approval: existing enrolled course **topic-first** entry (link to the same Exam Prep untimed responder) with **marks-first** optional route in Exam Prep, both driven by *one* eligible-question inventory and response/evidence implementation. Avoid duplicate Practice engines and duplicate course-to-paper topic evidence.
- **Item/source integrity:** a published written item needs persistent response type, mark value, exam vs training classification, paper/option identity, source requirements, AO and levels, case/stimulus, rubric version and consented evidence. Filtering must not expose unreviewed or unavailable tariffs or ignore Paper 3 learner option picks.
- **Self-assessment / adaptive trust:** learner score provenance remains self-assessed; no objective mastery, readiness or precise weakness inference from that score alone. REV/Plan can recommend a long-response practice *because a relevant exam demand exists* or an independently measured weakness suggests it; self-assessment can suggest uncertain follow-up, not overwrite independently scored evidence.
- **Timing:** optional practice timer and exam conditions are separate from real full-paper timing. Preserve 96/100-mark timed totals, existing finished zero marks, historical evidence IDs and existing course option paths.
- **Commercial:** propose tier-neutral essential authored exam writing/self-assessment. FI-007 calibrated assisted marking remains separately governed, costed and unenabled.
