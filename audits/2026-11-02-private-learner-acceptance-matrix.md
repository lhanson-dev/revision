## Purpose and evidence language

This is **one current acceptance control**, not a second specification audit, planner or feature backlog. Update its evidence cut, release and per-row **observed** results additively after new evidence; never rewrite an older observation into a pass. The matrix records what was actually exercised, by which mechanism, against which release, and what still requires a genuine learner or hosted system.

Other jobs: standard local email signup 1/1; pgTAP/RLS, static/unit/build, phone/tablet/desktop and security all passed (nine jobs total).
- **B (synthetic/browser fixture):** Playwright with synthetic learner state, mocked/local services or UI fixtures; proves controlled interface behaviour, **not** actual production Auth persistence, curriculum adequacy or authentic learner use. The current release's desktop jobs and responsive suites passed, with expected skips; inspect individual test setup before interpreting a pass.
- **P (production smoke):** automated read-only GET checks against deployed GitHub Pages; [job 125507683773](https://github.com/lhanson-dev/revision/actions/runs/41512285584/job/125507683773) confirms `/revision/app/` built assets/root redirect and legacy-route 404. **No authenticated journeys** were executed on hosted production by this smoke.
- **H (hosted authenticated session):** real controlled *non-child* signup/confirmation/sign-in/restore/retest on production. **No new H evidence available at this cut.** Do not use genuine child credentials, addresses or results in repository records.
- **O (direct learner observation):** Founder/family firsthand behaviour with browser/device, time, starting state, expected versus seen and follow-up retest. #765 contains valid **reported** issues; it is **not** a completed scripted acceptance session. Never conflate O with L, B or P.

**Verdicts:** `PASS—P`, `PASS—L`, `PASS—B` mean the **stated narrow assertion** passed only at that layer. `PARTIAL` means valuable narrower evidence, but the row's required genuine journey is not accepted. `BLOCKED` means required upstream condition absent. `OPEN` means no sufficient execution/retest evidence. No overall learner release-ready claim follows from isolated passes.
