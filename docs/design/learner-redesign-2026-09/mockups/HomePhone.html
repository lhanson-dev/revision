Current page (captured 30 Sep 2026)
Verdict

Right idea, heavy execution. The REV-first hero follows the Brand System, but the greeting is oversized, the only task below it is explained in system language, and the side panel is almost empty. Rating: needs polish.

Findings
HighGreeting overpowers the page

The heading renders at roughly 64px and wraps to three lines on desktop and five on phone, squeezed beside the Living E. The Brand System sets the Home greeting at Display L (44px desktop, 34px mobile). Copy also says "Hi" where the approved line is "Hey {first name}, what shall we do today?".

Standard: Visual Brand System · Typography, Learner Home
HighMissing quick actions and "continue where you left off"

The approved Home order is greeting, REV input, a small set of quick actions, then recent context. Only the input and one task exist, so a returning student has no fast route back into what they were doing.

Standard: Visual Brand System · Learner Home
MediumRecommendation explains itself in system terms

"Revision cannot tell whether it is strong or weak… establish an application baseline" asks the student to decode how the recommendation works. It should say what to do and why in plain words.

Standard: Tone of Voice · Rules
MediumEmpty "Today" panel

The right-hand card holds one sentence in a 390px-tall box. It reads unfinished and pushes the real task into a narrower column.

Standard: Product UX · cards group a clear job
MediumThe subject name competes with the greeting

"Business" is set at about 56px inside the card, while what matters (activity, topic, time, why) is small body text.

Standard: Visual Brand System · hierarchy
LowThree wordmarks in one view

Revision, Ask REV and a "Powered by REV" pill all sit in the first viewport. The pill adds nothing on a REV-first page.

Standard: Identity Asset Usage Rules
LowPhone hero is cramped

The Living E and heading sit side by side on a 390px screen. Stacking them gives the greeting the full width.

Standard: Visual Brand System · responsive layout
KeepKeep: dark Feature hero and one clear primary action

The Deep Teal feature surface, 48px controls and single "Start" action are on-brand. The mockup keeps them.

Standard: Visual Brand System · Surface families
What this mockup changes
  • Greeting set at Display L with the approved "Hey Alex…" copy, Living E and REV state above it.
  • Composer (52px+) with four quick actions. Try them: REV answers inline.
  • "Up next" card says what, how long and why in one plain sentence, with a clear Start button.
  • The empty panel becomes a real "Today" list tied to the plan, plus "Continue where you left off".
  • Phone: stacked hero, wordmark in the top bar, Ask REV dock with bottom clearance.
