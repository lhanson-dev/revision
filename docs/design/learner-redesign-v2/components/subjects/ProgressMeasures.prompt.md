Three separate progress measures for a course or subject (Course overview, Progress).

```jsx
<ProgressMeasures hue="blue" covered={4} total={10}
  understanding={{ gotit: 1, nearly: 2, needswork: 1, notstarted: 6 }}
  readinessNote="Do two timed answers to see this." />
```

Topics covered uses the subject hue; Understanding uses status colours; readiness is text.
