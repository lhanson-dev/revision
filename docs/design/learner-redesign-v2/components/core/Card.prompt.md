Flat card container plus `Stat` for big numbers. Use `tone="tint"` for highlight panels.

```jsx
<Card tone="tint" hue="violet" eyebrow="Next exam"><Stat value="23" unit="days" caption="Business Paper 1 mock · Thu 22 Oct" /></Card>
<Card title="This week">…</Card>
```

Never use the deep REV colour here — that's RevCard only.
