Pill-shaped action button; use for every tappable action. One `primary` per card.

```jsx
<Button variant="primary" size="lg" iconRight="arrowRight">Start practice</Button>
<Button variant="secondary" icon="plus">Add course</Button>
```

Variants: primary (teal), ink (dark fill, for Continue/Next), secondary (outlined), soft (teal tint), rev (translucent — only on the deep REV card). Sizes sm 34 / md 44 / lg 52.
