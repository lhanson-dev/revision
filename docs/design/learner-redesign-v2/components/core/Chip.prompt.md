Selectable pill for prompts, filters and onboarding picks.

```jsx
<Chip>Draw the graph</Chip>
<Chip selected solid hue="blue" size="lg">Business</Chip>
<Chip comingSoon size="lg">Sociology</Chip>
```

Unselected: surface + line border. Selected: tint + ink, or the solid subject hue (`solid`). `comingSoon` stays neutral even when selected.
