Line icon from the Revision set; use instead of drawing SVGs. Inherits `currentColor`.

```jsx
<Icon name="arrowRight" size={18} strokeWidth={2.6} />
```

UI: home, plan, progress, courses, check, arrowRight, arrowUp, plus, close, bolt, shield, clock, moon, lock.
Status (used by StatusBadge): gotit, nearly, needswork, started, notstarted.
