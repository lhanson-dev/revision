Topic understanding badge with five fixed states.

```jsx
<StatusBadge status="gotit" />      // Got it (teal)
<StatusBadge status="nearly" />     // Nearly there (yellow)
<StatusBadge status="needswork" />  // Needs work (coral, never error red)
<StatusBadge status="started" />    // Just started (neutral)
<StatusBadge status="notstarted" /> // Not started (neutral)
```

Status colours never appear on subjects, and subject colours never appear on status.
