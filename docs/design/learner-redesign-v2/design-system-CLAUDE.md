# Historical Claude Design project rules

> **DERIVED / HISTORICAL — NOT NORMATIVE AUTHORITY.**
>
> These instructions describe the 1 October 2026 Claude Design package. For any current learner-design task, start with `20-brand-and-experience/Learner Design System.md` and the specialist numbered authority located through `INDEX.md`. If anything below conflicts, the current numbered authority wins. Phase E will add the new bounded AI learner-design guide.

This project IS the Revision design system. Every new design here must follow it.

- Read `readme.md` first, then `guidelines/SUBJECT_PALETTE.md` and `guidelines/RESPONSIVE.md`.
- Use only the tokens in `tokens/` (via `styles.css`) and the components in `components/`. Don't invent colours, fonts, radii or new components without asking.
- Colour roles never mix. Teal = brand, REV, actions, links, focus. Teal / yellow / coral / neutral = status only (always icon + text). Subjects use the subject palette, the solid hue, and their letter mark.
- Progress = Topics covered · Understanding · Exam readiness. Never a single mastery %.
- The Living E is always moving (waiting / listening / thinking / responding), with a text label when motion is reduced.
- Layouts scroll down, never sideways: one 1100px canvas; sidebar > 960, icon rail 621–960, tab bar ≤ 620.
- No game styling (XP, streaks, badges, confetti). No "REV noticed" cards at launch.
- REV's voice: an older student who aced these subjects. Encouraging, specific, honest, never claims to be human. Every suggestion gives a reason.
- Current screens: `ui_kits/learner_app/index.html` (gallery: `Revision Screens v2.1.dc.html`). Everything in `archive/` is superseded. Never build from it.
- When a rule changes, update the tokens, components, `readme.md` and `design_handoff_revision_v2/CHANGES_v2.1.md` together.
