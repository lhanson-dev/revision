Answer

Paper 2 answer blueprints

The objective is not longer answers. It is more marks per sentence.

BLT — build analysis

Use case evidence and push each point beyond the obvious.

Case fact→Because→Leading to→Therefore
If the chain ends at “profit increases”, ask why that matters to this business now.

MOPS — earn evaluation

Use these filters to make a judgement specific rather than generic.

MagnitudeObjectiveProbabilityShort vs long term
Finish with a decision: which factor matters most, why, and what does it depend on?

Calculation questions

Formula→Substitute→Workings→Answer + unit

Never hide workings. If the final number is wrong, correct method can still matter.

Case-study application

Use a number/name/fact→Explain why it changes the argument
Weak: “Training improves productivity.”
Stronger: connect training to a fact in the case, then to cost, output, quality or the business objective.

Analyse

1. Make one relevant point.
2. Apply it to the case.
3. BLT the consequence twice.
4. If useful, show the counter-effect.

Evaluate / assess

1. Analyse the strongest argument for.
2. Analyse the strongest argument against/alternative.
3. Compare using MOPS.
4. Make a supported judgement rooted in the case.
