# Awarding Body URL Content Intake Workflow

## Purpose
Make the minimum input for adding a new Revision subject/course an official awarding-body course or specification URL, while preserving the controls in `Content Pack Production and Assurance Workflow.md`.

This workflow is an intake extension to Stages 1–3 of the Content Pack Production and Assurance Workflow. It does not weaken source, coverage, accuracy, CI, publication or human-review gates.

## Preferred Founder input

For an ordinary new course, the Founder may provide only an official awarding-body URL, for example an AQA qualification/specification page, with an instruction such as:

> Add this course to Revision using the approved content workflow: [official URL]

The Founder should not have to manually provide subject, qualification, awarding body, specification code, paper names or assessment structure when those can be resolved reliably from the official source.

## Intake rules

When an official course/specification URL is supplied, the agent must:

1. verify that the URL is an official awarding-body source rather than a third-party revision page;
2. resolve the subject, qualification level, awarding body and specification code/identifier from the official source;
3. establish whether the specification is current for the learner/exam cohort and record any withdrawal or replacement date that affects use;
4. identify all papers/components and their assessment structure, including marks, duration, weighting and assessment objectives where published;
5. follow the official course page to the relevant specification, subject-content, assessment, specimen/past-paper, mark-scheme and examiner/report resources needed by the governed content workflow;
6. create the source/provenance record from those official resources;
7. build the specification coverage blueprint before substantial learner content is generated;
8. preserve subject-authentic structure rather than forcing the course into an existing Business-shaped content model.

The supplied URL is the **starting authority pointer**, not automatically the only source required. The agent is responsible for following the official awarding-body source set needed to establish curriculum and assessment truth.

## Confirmation behaviour

Do not ask the Founder to repeat information that can be resolved from the official URL.

Before full content production, provide a concise resolved intake summary containing:

- subject;
- qualification;
- awarding body;
- specification code/identifier;
- current cohort/series validity where relevant;
- identified papers/components;
- any learner-specific option that cannot be inferred from the course URL.

Proceed without an additional clarification when the requested scope is unambiguous.

Ask a focused question only when a genuine learner-specific choice remains unresolved, for example:

- prescribed text, film or literary work;
- optional module/topic;
- tier or pathway;
- language option;
- paper/component subset where the Founder has asked for less than the whole course;
- exam cohort where multiple specifications could plausibly apply.

Do not use clarification as a substitute for reading the official source.

## Default scope when only a course URL is supplied

If the URL identifies a qualification containing multiple compulsory papers/components and the Founder says **add the course**, treat the course as the requested product scope and model its compulsory papers/components as coordinated content packs or components according to the governed content architecture.

If the Founder says **add this paper/component**, scope production to that component while still reading enough of the whole-course specification to understand synoptic, cross-component or shared-content requirements.

Where the current content schema cannot represent the authentic course structure without distortion, stop and classify that as a schema/architecture requirement rather than silently simplifying the subject.

## Source safety and currency

The agent must not assume that the first search result, an old PDF, or a familiar specification code is current.

The official awarding-body site must be used to confirm:

- current specification/version;
- first/last assessment dates where relevant;
- amendments or notices that materially affect content;
- current paper/component structure.

If the supplied URL redirects to a replaced or withdrawn qualification, surface that before content production and identify the current official replacement where possible.

## Output into the main content workflow

Successful URL intake must produce the information required by the existing governed workflow:

**Official URL → resolved course identity → official source set → source record → coverage blueprint → typed content pack → Content Accuracy Assurance Gate → CI → preview/pilot publication → portable human-review PDF → human subject-review gate.**

All existing Founder merge approvals remain required.

## Documentation impact

This workflow changes the intake burden, not the educational assurance standard or learner product architecture. It should be used as the preferred intake method for awarding bodies where a reliable official course/specification URL is available.
