# Manrope source and licence provenance

**Purpose:** record the authoritative source and licence metadata for the approved Revision typeface without redistributing font binaries.

## Typeface

- Family: **Manrope**
- Revision role: approved primary brand and product typeface
- Runtime source: Google Fonts stylesheet referenced by `app/index.html`
- Runtime weights: 400, 500, 600, 700, 800
- Canonical Google Fonts repository path: `google/fonts/ofl/manrope/`
- Copyright notice: Copyright 2018 The Manrope Project Authors
- Licence: **SIL Open Font License, Version 1.1 (OFL-1.1)**

## Production rule

Revision currently loads Manrope remotely from Google Fonts and does not store or redistribute font binaries in `assets/brand/`.

If Revision later self-hosts or bundles Manrope font files, the applicable copyright and OFL-1.1 licence notice must ship with the distributed font software in accordance with the licence terms. This metadata record does not replace that obligation.

## Source references

- Runtime stylesheet: `https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700;800&display=swap`
- Google Fonts source/licence: `https://github.com/google/fonts/tree/main/ofl/manrope`
- OFL text for Manrope: `https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt`

No font files are stored in this repository package by this record.
